# Big Reactors Client

## Dateien

- `ReactorBigReactors043A_Touch_Responsive.lua` – lokale grafische Reactor-Steuerung
- `ReactorBigReactors043A_Network.lua` – Netzwerk-Client

## Aufbau

OpenComputers-Computer → Modem + Big-Reactors-Computer-Port → Reactor.

Die Control-Rod-Steuerung benötigt eine funktionierende Verbindung zum Reactor-Computer-Port.

Bei Problemen zuerst die lokale GUI testen. Danach den Network-Controller starten.
