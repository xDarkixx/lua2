# SGCraft Client

## Dateien

- `SGCraft_Modern.lua` – lokale grafische Stargate-Steuerung
- `SGCraftNetwork_Modern.lua` – Netzwerk-Client

## Aufbau

OpenComputers-Computer → Modem → BULDACITY/2 Netzwerk.

Zusätzlich muss die SGCraft-Komponente bzw. der passende Adapter korrekt mit dem Computer verbunden sein.

Wenn die GUI `OFFLINE` zeigt, zuerst die lokal erkannte SGCraft-Komponente und deren verfügbare Methoden prüfen.
