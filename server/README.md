# BULDACITY Server

Hier gehören langfristig die Zentraldateien hinein.

Aktuell bleiben die funktionierenden Root-Dateien bewusst erhalten, damit bestehende Installationen nicht kaputtgehen.

Wichtige Serverdateien:

- `BuldacityOS_Tier3.lua`
- `BuldacityNetworkSetup.lua`
- `Network.lua`
- `BuldacityUI.lua`

Die eigentliche Migration der Lua-Dateien erfolgt erst, wenn alle Start- und Importpfade angepasst und getestet sind.
