# BULDACITY Netzwerk

Hier wird der Netzwerkbereich gesammelt.

Die zentrale, bereits funktionierende Netzwerkimplementierung bleibt vorerst als `Network.lua` im Root erhalten. Dadurch bleiben alte Installationen kompatibel.

Wichtig:

- Protokoll: `BULDACITY/2`
- Port: `4242`
- automatische Modem-Erkennung
- automatische Wireless-Erkennung
- Client Discovery
- LINK/PING/PONG
- Komponenten-Abfrage

Nicht benötigte manuelle UUID-Listen sind nicht vorgesehen.
