# 🔧 BULDACITY – Hardware und Aufbau

## Zentrale

Empfohlen:

- Tier-3-Computer
- GPU
- Bildschirm
- Keyboard
- Modem
- Internet Card nur wenn du sie für zusätzliche Online-Funktionen brauchst

## Client

Ein Client-PC benötigt mindestens:

- OpenComputers-Computer
- GPU + Bildschirm für die grafische Oberfläche
- Modem für BULDACITY/2
- den passenden Mod-Adapter bzw. die passende Mod-Komponente

## Grundregel

Das Mod-Gerät muss **wirklich mit dem OpenComputers-Computer verbunden** sein. Ein vorhandener Adapter bedeutet nicht automatisch, dass jede Mod-Funktion verfügbar ist.

## Big Reactors

Für den Reactor-Controller muss der OpenComputers-Computer auf den passenden Big-Reactors-Computer-Port zugreifen können. Wenn die Control Rods nicht reagieren, zuerst Verbindung und erkannte Komponente prüfen.

## Netzwerk

```text
[Computer] -- [Modem]
                  ))))))
              BULDACITY/2
                  (((((
[Modem] -- [Computer]
```

Wired und Wireless können je nach OpenComputers-Hardware verwendet werden. BULDACITY versucht die vorhandenen Modems automatisch zu erkennen.
